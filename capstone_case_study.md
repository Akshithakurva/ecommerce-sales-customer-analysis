# E-Commerce Sales & Customer Analysis
## Google Data Analytics Certificate Portfolio Project

### Business task
An online retailer wants to understand sales performance, profitability, customer contribution, and regional trends so managers can make better decisions.

### Ask
- Which products and categories drive revenue?
- Which products have weaker margins?
- How does sales performance change over time?
- Which cities and customers contribute the most?
- What actions could improve profitability?

### Prepare
The dataset contains 500 cleaned transaction records with order date, customer, product, category, city, quantity, price, discount, sales, and profit.

### Process
- Removed duplicate transaction records.
- Checked missing values.
- Filled missing categorical values using the mode and missing discount values using the median.
- Standardized date fields and created month/year fields.
- Created a profit-margin metric.

### Analyze
**Total sales:** ₹12,163,952  
**Total profit:** ₹1,550,174  
**Orders:** 500  
**Average order value:** ₹24,328  
**Overall profit margin:** 12.74%

### Share
Create a Tableau dashboard with KPI cards, a monthly sales trend, product/category charts, a city view, and a top-customer table.

### Act
Potential business actions:
1. Protect high-revenue products while monitoring their margins.
2. Investigate low-margin products for pricing, supplier, or discount improvements.
3. Study high-performing cities for targeted marketing.
4. Use top-customer behavior to design retention offers.
5. Monitor monthly trends to improve inventory and campaign planning.

### Tools demonstrated
Google Data Analytics methodology, spreadsheets, SQL, Tableau, Python, data cleaning, exploratory analysis, visualization, and business recommendations.

# Google Data Analytics Certificate Portfolio Project

## Project
**E-Commerce Sales & Customer Analysis**

This project is intentionally aligned to the skills shown in the Google Data Analytics Professional Certificate:
- Ask questions and define the business problem
- Prepare data
- Process/clean data
- Analyze data
- Share insights through visualization
- Python for data analysis
- SQL
- Spreadsheets
- Tableau
- Case-study style communication

## Portfolio workflow
ASK -> PREPARE -> PROCESS -> ANALYZE -> SHARE -> ACT

## Files
- ecommerce_sales_cleaned.csv — main dataset
- ecommerce_analysis_workbook.xlsx — spreadsheet analysis
- analysis_queries.sql — SQL analysis
- python_eda.py — Python EDA
- tableau_dashboard_guide.md — Tableau dashboard instructions
- capstone_case_study.md — final case-study write-up

## Resume bullet
**E-Commerce Sales & Customer Analysis | Excel, SQL, Python, Tableau**
- Cleaned and analyzed 500+ e-commerce transactions using spreadsheet techniques, SQL, and Python.
- Performed exploratory data analysis to identify product, customer, regional, and monthly sales trends.
- Built a Tableau dashboard with KPI cards, sales trends, product/category performance, and customer insights.
- Converted findings into actionable recommendations focused on profitability, customer retention, and regional performance.
